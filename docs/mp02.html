Introduction

For a commuter-based city such as New York, more than 50% of the population rely on public transportation to commute to various areas across the city. People tend to grow up in the city never learning how to drive because often times it is simply much easier to just take the public transportation. From youth to adulthood, the public transportation system has always been apart of our lives from when we were students all the way to our daily work commutes. However, regardless of which form of commute you take, there will always be toxic carbon emissions being emitted from each type of vehicle.

This analysis examines various datasets across multiple travel agencies about electricity, fuel usage, as well as passenger information to better understand how different factors correlate with the environmental performance across travel agencies.

Data Acquisition and Preparation

To evaluate transit agencies, I looked at three sources of information. The EIA state electricity profiles provide estimates of carbon emissions associated with electricity generation. The NTD energy dataset reports the fuel and electricity consumed by transit agencies, while the NTD service dataset provides information about passenger trips and passenger miles.

These datasets serve various purposes, so they need to be cleaned and combined before I can use them to estimate emissions and compare agencies. We also used 8 different questions to help guide our understanding of the data.

get_eia_sep <- function(state, abbr) {
  library(tidyverse)
  library(stringr)
  library(httr2)
  library(rvest)
  library(fs)

  state_formatted <- str_to_lower(state) |>
    str_replace_all("\\s", "")

  dir_name <- fs::path("data", "mp02")
  file_name <- fs::path(dir_name, state_formatted)

  fs::dir_create(dir_name, recurse = TRUE)

  if (!fs::file_exists(file_name)) {
    BASE_URL <- "https://www.eia.gov"

    RESPONSE <- request(BASE_URL) |>
      req_url_path(
        "electricity",
        "state",
        state_formatted
      ) |>
      req_headers(
        `User-Agent` = "Mozilla/5.0 (Macintosh; Intel Mac OS X 10.15; rv:149.0) Gecko/20100101 Firefox/149.0"
      ) |>
      req_retry(max_tries = 4) |>
      req_perform(file_name)

    resp_check_status(RESPONSE)
  }

  TABLE <- read_html(file_name) |>
    html_element("table") |>
    html_table() |>
    mutate(Item = str_to_lower(Item))

  if ("U.S. rank" %in% colnames(TABLE)) {
    TABLE <- TABLE |> rename(Rank = `U.S. rank`)
  }

  CO2_MWh <- TABLE |>
    filter(Item == "carbon dioxide (lbs/mwh)") |>
    pull(Value) |>
    str_replace_all(",", "") |>
    as.numeric()

  PRIMARY <- TABLE |>
    filter(Item == "primary energy source") |>
    pull(Rank)

  RATE <- TABLE |>
    filter(Item == "average retail price (cents/kwh)") |>
    pull(Value) |>
    as.numeric()

  GENERATION_MWh <- TABLE |>
    filter(Item == "net generation (megawatthours)") |>
    pull(Value) |>
    str_replace_all(",", "") |>
    as.numeric()

  data.frame(
    CO2_MWh = CO2_MWh,
    primary_source = PRIMARY,
    electricity_price_MWh = RATE * 10,
    generation_MWh = GENERATION_MWh,
    state = state,
    abbreviation = abbr
  )
}

load_ntd_energy <- function() {
  library(readxl)
  library(httr2)
  library(tidyverse)
  library(fs)

  DATA_DIR <- fs::path("data", "mp02")
  fs::dir_create(DATA_DIR, recurse = TRUE)

  NTD_ENERGY_FILE <- fs::path(DATA_DIR, "2025_ntd_energy.xlsx")

  if (!fs::file_exists(NTD_ENERGY_FILE)) {
    request("https://www.transit.dot.gov/") |>
      req_url_path(
        "sites",
        "fta.dot.gov",
        "files",
        "2026-09",
        "2025 Energy Consumption_260806.xlsx"
      ) |>
      req_headers(
        `User-Agent` = "Mozilla/5.0 (Macintosh; Intel Mac OS X 10.15; rv:149.0) Gecko/20100101 Firefox/149.0"
      ) |>
      req_perform(NTD_ENERGY_FILE)
  }

  if (file.info(NTD_ENERGY_FILE)$size < 1e4) {
    cat("I was unable to download the NTD Energy File. Please try again.\n")
    stop("Download failed. Please delete the corrupted file by running `unlink('data/mp02/2025_ntd_energy.xlsx')` and try again.")
  }

  to_numeric_fill_0 <- function(x) {
    x <- if_else(x == "-", NA, x)
    replace_na(as.numeric(x), 0)
  }

  read_excel(NTD_ENERGY_FILE) |>
    select(-c(
      `Reporter Type`,
      `Reporting Module`,
      `Gallons of Other Fuel`,
      `Other Fuel Description`
    )) |>
    mutate(across(
      -c(`Agency Name`, `Mode`, `TOS`),
      to_numeric_fill_0
    )) |>
    group_by(`NTD ID`, `Mode`, `Agency Name`) |>
    summarize(
      across(where(is.numeric), sum),
      .groups = "keep"
    ) |>
    
mutate(ENERGY = rowSums(across(
  c(starts_with("Gallons of"), starts_with("Kilowatt hours"))
))) |>
filter(ENERGY > 0) |>
select(-ENERGY) |>
ungroup()

}

NTD_ENERGY <- load_ntd_energy()

load_ntd_service <- function() {
  library(httr2)
  library(tidyverse)
  library(fs)

  DATA_DIR <- fs::path("data", "mp02")
  fs::dir_create(DATA_DIR, recurse = TRUE)

  NTD_SERVICE_FILE <- fs::path(DATA_DIR, "2025_ntd_service.csv")

  if (!fs::file_exists(NTD_SERVICE_FILE)) {
    request("https://data.transportation.gov/resource/4fir-qbim.csv") |>
      req_url_query(`$query` = paste(
        "SELECT `_5_digit_ntd_id` AS `NTD_ID`",
        "`max_agency` AS `AGENCY`",
        "`max_reporter_type` AS `reporter_type`",
        "`max_organization_type` AS `organization_type`",
        "`max_city` AS `city`",
        "`max_state` AS `state`",
        "`mode`",
        "`type_of_service`",
        "`max_primary_uza_code` as `uza_code`",
        "`max_primary_uza_name` as `uza_name`",
        "`max_primary_uza_area_sq_miles` as `uza_sq_miles`",
        "`max_primary_uza_population` as `uza_population`",
        "`max_service_area_sq_miles` as `service_area_sq_miles`",
        "`max_service_area_population` as `service_area_population`",
        "`questionable_record` as `flagged_likely_inaccurate`",
        "`sum_unlinked_passenger_trips_upt` as `total_upt`",
        "`sum_passenger_miles` WHERE caseless_one_of(`report_year`, '2025') limit 50000",
        sep = ","
      )) |>
      req_headers(
        `User-Agent` = "Mozilla/5.0 (Macintosh; Intel Mac OS X 10.15; rv:149.0) Gecko/20100101 Firefox/149.0"
      ) |>
      req_perform(NTD_SERVICE_FILE)
  }

  if (file.info(NTD_SERVICE_FILE)$size < 1e4) {
    cat("I was unable to download the NTD Service File. Please try again.\n")
    stop("Download failed. Please delete the corrupted file and try again.")
  }

  read_csv(NTD_SERVICE_FILE) |>
    mutate(flagged_likely_inaccurate = !is.na(flagged_likely_inaccurate))
}

NTD_SERVICE <- load_ntd_service()

Exploratory Analysis

Before calculating the emissions for the individual transit agencies, I examined patterns in electricity generation and transportation fuel usage.

One finding is that electricity emissions vary considerably across states. West Virginia has the highest reported emissions rate in this dataset at 1,912 pounds of CO₂ per MWh, compared with only 8 pounds per MWh in Vermont. This suggests that an electric transit system’s estimated environmental impact can partially depend on where it operates.

The transit energy data also shows that diesel fuel remains a major source of energy consumption, with New Jersey Transit Corporation and MTA New York City Transit reporting the highest total gallon usage among the agencies examined.

Final Insights and Deliverable

After exploring the individual datasets, I combined the transit energy records with passenger service information and state electricity emissions rates. This allowed me to estimate the amount of CO₂ associated with each agency’s fuel and electricity consumption.

The combined dataset contains a total of 1,134 agency-and-mode records. Four records do not have complete emissions estimates. For the remaining records, the estimated total is approximately 18.73 billion pounds of CO₂.

To compare agencies of different sizes, I calculated emissions per passenger trip and per passenger mile. The passenger-mile measurement is the main basis for the awards because it accounts for both ridership and distance traveled.

# Task 5b: Estimate CO2 emissions in pounds
# Source: https://www.eia.gov/environment/emissions/co2_vol_mass.php
# Bio-diesel and ethanol use conventional fuel approximations.
# Hydrogen has zero direct-use CO2 emissions.

diesel_factor <- 22.45
gasoline_factor <- 18.73
propane_factor <- 12.68
kerosene_factor <- 21.78
bunker_factor <- 24.78

# Natural gas approximation using gallon equivalents
natural_gas_factor <- 117 / 1000 * 126.67

TRANSIT_EMISSIONS <- TRANSIT_COMBINED |>
  mutate(
    electricity_kwh =
      `Kilowatt hours of Electric Battery` +
      `Kilowatt hours of Electric Propulsion`,

    electricity_co2_lbs = if_else(
      electricity_kwh > 0 & is.na(CO2_MWh),
      NA_real_,
      electricity_kwh / 1000 * coalesce(CO2_MWh, 0)
    ),

    fuel_co2_lbs =
      `Gallons of Diesel Fuel` * diesel_factor +
      `Gallons of Gasoline` * gasoline_factor +
      `Gallons of Bio-Diesel` * diesel_factor +
      `Gallons of Ethanol` * gasoline_factor +
      `Gallons of Kerosene` * kerosene_factor +
      `Gallons of Bunker Fuel` * bunker_factor +
      `Gallons of Compressed Natural Gas` * natural_gas_factor +
      `Gallons of Liquified Nat Gas` * natural_gas_factor +
      `Gallons of Liquified Petroleum Gas` * propane_factor,

    total_co2_lbs = fuel_co2_lbs + electricity_co2_lbs
  )


TRANSIT_EMISSIONS |>
  summarise(
    `Total Records` = n(),
    `Records Missing Emissions` = sum(is.na(total_co2_lbs)),
    `Estimated CO2 Emissions (lbs)` = sum(total_co2_lbs, na.rm = TRUE)
  ) |>
  knitr::kable(
    format.args = list(big.mark = ",", scientific = FALSE),
    caption = "Estimated Carbon Dioxide Emissions"
  )

    total_co2_lbs = if (any(is.na(total_co2_lbs))) {
      NA_real_
    } else {
      sum(total_co2_lbs)
    },
    total_upt = sum(total_upt, na.rm = TRUE),
    passenger_miles = sum(passenger_miles, na.rm = TRUE),
    .groups = "drop"
  ) |>
  mutate(
    co2_per_trip = if_else(
      total_upt > 0,
      total_co2_lbs / total_upt,
      NA_real_
    ),
    co2_per_passenger_mile = if_else(
      passenger_miles > 0,
      total_co2_lbs / passenger_miles,
      NA_real_
    )
  )

For a commuter-based city such as New York, more than 50% of the population rely on public transportation to commute to various areas across the city. People tend to grow up in the city never learning how to drive because often times it is simply much easier to just take the public transportation. From youth to adulthood, the public transportation system has always been apart of our lives from when we were students all the way to our daily work commutes. However, regardless of which form of commute you take, there will always be toxic carbon emissions being emitted from each type of vehicle. 

This analysis examines various datasets across multiple travel agencies about electricity, fuel usage, as well as passenger information to better understand how different factors correlate with the environmental performance across travel agencies.

```{r}
get_eia_sep <- function(state, abbr) {
  library(tidyverse)
  library(stringr)
  library(httr2)
  library(rvest)
  library(fs)

  state_formatted <- str_to_lower(state) |>
    str_replace_all("\\s", "")

  dir_name <- fs::path("data", "mp02")
  file_name <- fs::path(dir_name, state_formatted)

  fs::dir_create(dir_name, recurse = TRUE)

  if (!fs::file_exists(file_name)) {
    BASE_URL <- "https://www.eia.gov"

    RESPONSE <- request(BASE_URL) |>
      req_url_path(
        "electricity",
        "state",
        state_formatted
      ) |>
      req_headers(
        `User-Agent` = "Mozilla/5.0 (Macintosh; Intel Mac OS X 10.15; rv:149.0) Gecko/20100101 Firefox/149.0"
      ) |>
      req_retry(max_tries = 4) |>
      req_perform(file_name)

    resp_check_status(RESPONSE)
  }

  TABLE <- read_html(file_name) |>
    html_element("table") |>
    html_table() |>
    mutate(Item = str_to_lower(Item))

  if ("U.S. rank" %in% colnames(TABLE)) {
    TABLE <- TABLE |> rename(Rank = `U.S. rank`)
  }

  CO2_MWh <- TABLE |>
    filter(Item == "carbon dioxide (lbs/mwh)") |>
    pull(Value) |>
    str_replace_all(",", "") |>
    as.numeric()

  PRIMARY <- TABLE |>
    filter(Item == "primary energy source") |>
    pull(Rank)

  RATE <- TABLE |>
    filter(Item == "average retail price (cents/kwh)") |>
    pull(Value) |>
    as.numeric()

  GENERATION_MWh <- TABLE |>
    filter(Item == "net generation (megawatthours)") |>
    pull(Value) |>
    str_replace_all(",", "") |>
    as.numeric()

  data.frame(
    CO2_MWh = CO2_MWh,
    primary_source = PRIMARY,
    electricity_price_MWh = RATE * 10,
    generation_MWh = GENERATION_MWh,
    state = state,
    abbreviation = abbr
  )
}
```

```{r}
load_ntd_service <- function() {

  if (!fs::file_exists(NTD_SERVICE_FILE)) {

      req_url_query(`$query` = paste(
        "SELECT `_5_digit_ntd_id` AS `NTD_ID`",
        "`max_agency` AS `AGENCY`",
        "`max_reporter_type` AS `reporter_type`",
        "`max_organization_type` AS `organization_type`",
        "`max_city` AS `city`",
        "`max_state` AS `state`",
        "`mode`",
        "`type_of_service`",
        "`max_primary_uza_code` as `uza_code`",
        "`max_primary_uza_name` as `uza_name`",
        "`max_primary_uza_area_sq_miles` as `uza_sq_miles`",

        "`questionable_record` as `flagged_likely_inaccurate`",
```

### Task 5b: Estimate Carbon Dioxide Emissions


```{r}
# Task 5b: Estimate CO2 emissions in pounds
# Source: https://www.eia.gov/environment/emissions/co2_vol_mass.php
# Bio-diesel and ethanol use conventional fuel approximations.
# Hydrogen has zero direct-use CO2 emissions.

diesel_factor <- 22.45
gasoline_factor <- 18.73
propane_factor <- 12.68
kerosene_factor <- 21.78
bunker_factor <- 24.78

# Natural gas approximation using gallon equivalents
natural_gas_factor <- 117 / 1000 * 126.67

TRANSIT_EMISSIONS <- TRANSIT_COMBINED |>
  mutate(
    electricity_kwh =
      `Kilowatt hours of Electric Battery` +
      `Kilowatt hours of Electric Propulsion`,

    electricity_co2_lbs = if_else(
      electricity_kwh > 0 & is.na(CO2_MWh),
      NA_real_,
      electricity_kwh / 1000 * coalesce(CO2_MWh, 0)
    ),

    fuel_co2_lbs =
      `Gallons of Diesel Fuel` * diesel_factor +
      `Gallons of Gasoline` * gasoline_factor +
      `Gallons of Bio-Diesel` * diesel_factor +
      `Gallons of Ethanol` * gasoline_factor +
      `Gallons of Kerosene` * kerosene_factor +
      `Gallons of Bunker Fuel` * bunker_factor +
      `Gallons of Compressed Natural Gas` * natural_gas_factor +
      `Gallons of Liquified Nat Gas` * natural_gas_factor +
      `Gallons of Liquified Petroleum Gas` * propane_factor,

    total_co2_lbs = fuel_co2_lbs + electricity_co2_lbs
  )


TRANSIT_EMISSIONS |>
  summarise(
    `Total Records` = n(),
    `Records Missing Emissions` = sum(is.na(total_co2_lbs)),
    `Estimated CO2 Emissions (lbs)` = sum(total_co2_lbs, na.rm = TRUE)
  ) |>
  knitr::kable(
    format.args = list(big.mark = ",", scientific = FALSE),
    caption = "Estimated Carbon Dioxide Emissions"
  )
```

### Green Transit Alliance Award Announcements
## Green Transit Alliance Recognizes Leading U.S. Public Transit Agencies

The Green Transit Alliance is recognizing two public transportation agencies for their relatively low estimated carbon dioxide emissions in its analysis of 2025 transit operations.

**Greenest Transit Agency: City of Seattle**

The City of Seattle ranks first overall, with approximately **0.0639 pounds of CO₂ per passenger mile** and more than 2 million reported passenger miles. This award recognizes the agency with the lowest estimated emissions relative to the passenger distance it provides.

The result is especially notable when compared with the median agency emissions rate of **`r round(median(AWARD_CANDIDATES$co2_per_passenger_mile), 4)`** pounds of CO₂ per passenger mile.

**Greenest Large Transit Agency: Tri-County Metropolitan Transportation District of Oregon**

For agencies providing at least 10 million passenger miles, the Tri-County Metropolitan Transportation District of Oregon ranks first, with approximately **0.0974 pounds of CO₂ per passenger mile** across nearly 270 million passenger miles.

The median among eligible large agencies is **`r round(median(AWARD_CANDIDATES$co2_per_passenger_mile[AWARD_CANDIDATES$passenger_miles >= 10000000]), 4)`** pounds of CO₂ per passenger mile.

**Understanding the Results**

These awards are based on estimated emissions from reported fuel consumption and state-level electricity generation. They do not measure every environmental impact associated with transit operations, and they do not directly calculate the emissions avoided when passengers choose transit instead of driving.

The findings nevertheless provide a way to compare the estimated operating emissions of transit agencies while considering the passenger transportation they deliver.
